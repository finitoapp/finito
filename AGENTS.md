# AGENTS Instructions

## Evolu write rules
- Use `evolu.update` for partial changes of an existing row.
- Use `evolu.upsert` for creating a row or writing a coherent row state; include all non-null fields required for a valid state.
- Use `evolu.insert` like `evolu.upsert`, but with `id` generated by Evolu, which creates a new row.

## Error rules
- Define new typed errors with `defineError` from `lib/shared/error.ts`.
- Name error factories with the `create...Error` prefix, for example `createRpcResponseTimeoutError`.
- Export the error type as `ReturnType<typeof create...Error>`.
- Prefer plain typed error objects with a `type` discriminant over error classes.
- When checking an error variant, branch by `error.type`.

## Result rules
- Prefer `Result` from `@evolu/common` for fallible operations instead of unions like `T | Error`.
- Return success with `ok(value)` and failure with `err(error)`.
- Narrow results with `result.ok`.
- For callback-based APIs, pass `Result` values consistently to the callback as well.
- Keep result error types explicit, for example `Result<Value, MyError | OtherError>`.
